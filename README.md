## 🚀 Projects

### 1. Post-Flood Electrical Safety Monitoring System

**Technologies:** ESP32 DevKit V1, IoT, Blynk, Moisture Sensors, Current Transformers, Relay Modules

An IoT-based electrical safety monitoring system designed to detect potential electrical hazards in flood-affected environments.

- ESP32-based monitoring and control.
- Multiple moisture sensor inputs for water detection.
- Current transformer integration for electrical leakage monitoring.
- Relay-controlled electrical outlet isolation.
- Blynk dashboard for remote monitoring.
- Automated hazard detection using moisture and current sensor readings.
- LED indicators for system and hazard status.

### 2. Learsi's Point of Sale (POS) System

**Technologies:** Flutter, Dart, Python, FastAPI, REST API, Loyverse API

A restaurant point-of-sale application designed to improve table management, menu handling, and order processing.

- Flutter-based POS application.
- FastAPI backend development.
- Dynamic menu and category retrieval through Loyverse API.
- Interactive restaurant table management.
- Table reservation and waiting status functionality.
- Order customization with item remarks and presets.
- Quantity management and order processing.
- Backend API integration between the mobile application and server.

### 3. Arduino AVR Register-Level 7-Segment Display

**Technologies:** Arduino, C/C++, AVR Registers, GPIO, Analog Input

A microcontroller programming project focused on low-level hardware control and direct register manipulation.

- Direct DDRx and PORTx register manipulation.
- Seven-segment display interfacing.
- Common-anode display configuration.
- Potentiometer input processing through analog channels.
- Push-button-controlled laboratory mode switching.
- Direct microcontroller I/O control.

### 4. Sound and Temperature Controlled Smart House Using PIC

**Technologies:** PIC Microcontroller, Embedded C, Sensors, Temperature Monitoring, Sound Detection, Automation

A microcontroller-based smart house project designed to demonstrate automated home functions using sound and temperature sensing.

- PIC microcontroller-based control system.
- Sound detection and input monitoring.
- Temperature sensing and monitoring.
- Automated responses based on sensor readings.
- Integration of hardware components and electronic circuits.

### 5. Design and Development of an Automated Draft Survey Using MEMS Pressure Sensor

**Technologies:** MEMS Differential Pressure Sensor, ESP32, Embedded Systems, Wireless Data Acquisition, Sensor Integration

An engineering thesis project focused on developing an automated vessel draft survey system using hydrostatic pressure measurements to determine vessel draft, displacement, and cargo mass.

- MEMS differential-pressure sensor integration.
- Hydrostatic pressure measurement for vessel draft determination.
- Microcontroller-based sensor data acquisition.
- Wireless transmission of measurement data.
- Pressure-to-draft conversion using hydrostatic principles.
- Vessel displacement and cargo-mass calculation.
- Centralized data processing and monitoring.
